# 设备与采购
> 来源：原手册附录 C。设备分工表见 [使用规则](../00-总览与规则/使用规则.md)。

1. 已有就用：i.MX6ULL Pro、Luckfox Pico Zero + ISG1321、PC。不为这个计划买新摄像头、Jetson 或昂贵示波器。
2. **逻辑分析仪**（W15 前到位）：用于 I2C/SPI/UART/PWM；软件用 PulseView。公司采购或自购入门款。
3. USB 转串口：先清点现有的，注意 3.3V TTL 与 RS-232 不能混接。
4. 示波器：有模拟/电源信号需求再要。普通逻辑分析仪抓不了 MIPI CSI 高速信号。
5. I2C/SPI 小器件：确认板子接口和需求后再买，别因为视频里用了 MPU6050 就照买。
