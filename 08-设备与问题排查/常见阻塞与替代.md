# 常见阻塞与替代方案
> 来源：原手册附录 D。卡住先查这张表，再写故障定位报告。

| 阻塞 | 先查 | 替代 |
|---|---|---|
| 模块 `invalid module format` | `uname -r`、vermagic、内核配置是否匹配 | 用匹配的源码重建，不要强制加载 |
| Luckfox 拉不出视频 | 镜像、IP、rkipc 进程、日志、排线 | 先走官方 RTSP + VLC，再接 OpenCV |
| OpenCV 打不开 RTSP | 是否带 FFmpeg/GStreamer、编码、URL | 用本地视频文件练习 |
| 找不到 `/dev/video*` | 是否已停掉 rkipc、是否在 Linux 主机上 | 读官方 `capture.c` 画流程，不虚构实测 |
| 没有合适 I2C/SPI 器件 | 接线、供电、电平 | 先做 UART/LED/按键；SPI 做回环；I2C 可试 `i2c-stub` |
| QEMU 内核难构建 | 配置、EDU 设备、initramfs | 先复用宿主内核 + 对应 headers |
| 某周超时 | 是不是 ⭐ 在挤占核心 | 删 ⭐，只留"最低可验证实验" |
