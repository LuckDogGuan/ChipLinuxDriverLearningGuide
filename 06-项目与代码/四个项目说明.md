## 每个项目的 README 至少要有

1. 一句话说明这是什么
2. 硬件 / 软件环境（板卡、内核版本、工具链版本）
3. 构建步骤（能复制粘贴执行）
4. 运行步骤与预期输出
5. 证据：截图、日志、波形的链接
6. 已知问题与限制（不隐瞒）
