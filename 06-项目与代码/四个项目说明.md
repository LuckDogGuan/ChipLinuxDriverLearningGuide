# 四个项目说明（P1–P4）

> 手册里的 4 个作品集项目，分散在各周完成。这里集中说明"做什么、在哪周做、交什么"，方便最后整理作品集。
> 代码先写在每周的 `code/wxx/`，项目成型后再整理进下面的作品集仓库。

## 总表

| 项目 | 做什么 | 在哪几周做 | 交付物 | 完成 |
|---|---|---|---|---|
| **P1**《i.MX6ULL 设备控制》 | I2C 读数 + 按键中断 + LED/PWM 指示 + 字符设备/sysfs 接口 | W13–W19 积累，W20 完成 | 源码、README、接线图、故障报告 | ☐ |
| **P2**《camdiag 数据通路测量》 | 测量摄像头一帧从采集到程序的帧数、丢帧、重连时间 | W21–W23 积累，W24 完成 | 工具 + 10 分钟运行数据 + 数据流图 + 故障表 + README | ☐ |
| **P3**《QEMU PCI EDU Driver》 | QEMU 里的 PCI 教学设备驱动：BAR/MMIO → 中断 → DMA | W28–W31 积累，W32 完成 | 仓库、构建脚本、功能测试、IRQ/DMA 日志、一次故障回归 | ☐ |
| **P4**《devdiag 设备诊断工具》 | 命令行工具，汇总板卡信息、内核/驱动状态、相机指标，输出诊断报告 | W37–W38 | 源码、README、稳定性报告 | ☐ |

## 每个项目的 README 至少要有

1. 一句话说明这是什么
2. 硬件 / 软件环境（板卡、内核版本、工具链版本）
3. 构建步骤（能复制粘贴执行）
4. 运行步骤与预期输出
5. 证据：截图、日志、波形的链接
6. 已知问题与限制（不隐瞒）
