# 五道门自测表

> 每个阶段末填一次。五道门全过才算这个阶段真正学会；没过的那一门写进下阶段第一周的周报。
> "证据"一栏写文件路径，例如 `04-笔记/W06/evidence/gdb.png`。

| 门 | 含义 |
|---|---|
| ① 功能能跑 | 代码在 PC 或板上真实运行，有日志或截图 |
| ② 能讲清机制 | 不看资料，3 分钟讲清原理 |
| ③ 能独立重写 | 删掉关键函数，不看答案能重写出来 |
| ④ 能复现并定位一个故障 | 有一份故障定位报告 |
| ⑤ 别人按 README 能复现 | 找个人（或换个干净环境）按 README 做一遍 |
