## 深化与故障定位

> 与上面的 D1–D6 课程配套，**替换**部分重复观看或练习，不额外增加固定学习时间；每周调试训练用 [六步定位法](../../05-学习校验/调试能力贯穿40周.md) 记录。70% 是训练重心，不是机械划分学时。

- **先看可视化（5–10 分钟）**：DMA CPU→设备→内存地址转换图；先直观理解现象，不追求一次精通。
- **再看一手资料（优先查相关一节）**：DMA API HOWTO: https://docs.kernel.org/core-api/dma-api-howto.html。记录实际版本/章节/关键函数或寄存器；[原始资料阅读方法](../../03-资料链接/一手资料阅读路线.md)。
- **本周定位挑战（🔧 与 D6 实验合并）**：DMA 数据损坏：对比地址掩码、方向、同步与缓冲范围。提交现象、两个假设、排除证据、根因/尚未知、回归结果。
- **减负与边界**：先把 coherent/streaming 讲清，不强制实现 IOMMU。任何硬件特性先以手册、实机配置和日志为准，失败可交阻塞报告。
- **可视化工具总表**：[可视化学习地图](../../03-资料链接/可视化学习地图.md)；报告见 [故障定位报告模板](../../07-模板/故障定位报告模板.md)。
