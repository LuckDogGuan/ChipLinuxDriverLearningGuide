# 芯片底层软件 40 周学习手册（最终版）

> 目标方向：芯片公司 Linux 驱动 / BSP / 固件 / 诊断与验证工具。
> 主线：C 与 Linux 系统编程 → i.MX6ULL 驱动 → 摄像头数据通路（小而完整）→ AArch64 与 PCI/DMA → 调试与工程化 → 作品集。
> 本手册是学习计划，不保证岗位或录用；以每个小阶段的**产出**和证据为准。
> 日期不绑定：你实际开始的那一周记为 W01。

---

## 0. 使用方法（先读这一页）

### 标签

| 标签 | 含义 | 规则 |
|---|---|---|
| ✅ | 必学 | 当周优先完成 |
| 🔧 | 动手必做 | 必须留下证据（日志、截图、波形、代码） |
| ⏩ | 你已有基础，可快进 | 先做自测，通过就 1.5–2 倍速或直接跳 |
| ⭐ | 选读 | 不计验收，看不完没关系，不能挤占 ✅ 和 🔧 |
| 🟡 | 条件必学 | 只有岗位需要或硬件到位才升级 |
| 📝 | 笔记与证据 | 与代码放同一仓库 |

### 每周时间（给笔记留足空间）

| 日 | 内容 | 上限 |
|---|---|---|
| D1–D4 | 视频/阅读 ≤60′ + 动手 ≤30′ + **笔记 15′** | 约 100′ |
| D5 | 选读或机动，没落后就休息 | ≤45′ |
| D6 | 周实验 + **周报 30′** | ≤150′ |
| D7 | 休息，不安排 | 0 |

- 正常周约 9–10 小时；**轻量周**（W05、W10、W15、W20、W25、W32、W40）≤6 小时，用来补课、整理笔记、做展示。
- 日子可以顺延，顺序不变；老板临时有事就往后挪，不通宵追。
- **最低版本**（一周只有 5 小时）：只做 D1–D3 + D6 的最小实验，D4、D5 全部顺延。
- 当周核心实验没跑通，可以交"可复现的阻塞日志 + 下一步验证清单"，下个小阶段继续。

### 笔记规则

- 每天 3 行：①今天学了什么（一句话）②一个没弄懂的点 ③一个能验证的小结论（代码片段/截图/波形）。
- 每周一个证据包（放进 Git）：

```
notes/Wxx/
  note.md       # 每日 3 行 + 本周总结
  code/         # 本周实验
  evidence/     # 截图、波形、日志、原理图标注
  report.md     # 周报
```

- **周报 5 项**：目标 / 做了什么 / 证据 / 遇到的问题与定位过程 / 下周只做一件事。

### 每个阶段末用五道门自测

功能能跑 / 能讲清机制 / 能独立重写关键部分 / 能复现并定位一个故障 / 别人按 README 能复现。

### 设备分工（不要混用）

| 设备 | 用途 | 注意 |
|---|---|---|
| 野火 i.MX6ULL Pro | ARMv7 Linux、交叉编译、内核/设备树/驱动 | 32 位 Cortex-A7，不是 AArch64 板 |
| Luckfox Pico Zero + ISG1321 | MIPI CSI 采集、RTSP、V4L2 原始帧 | 见第 4 节；ISG1321 是**黑白**全局快门相机 |
| PC（Ubuntu 虚拟机/WSL2） | C/C++、GDB、CMake、OpenCV、QEMU | WSL2 下 USB 设备与 KVM 受限 |
| QEMU | AArch64 裸机、x86_64 的 PCI EDU 设备 | 只是软件模型，不等于真实 PCIe 链路调试 |

## 4. 摄像头数据通路说明

```text
路径 A（先跑通，官方 demo）
ISG1321 → MIPI CSI → RV1106 的 ISP/编码（rkipc）→ RTSP → USB 网口/Wi-Fi → PC（VLC / OpenCV）

路径 B（学 Linux 采集接口）
ISG1321 → CSI → V4L2 设备节点（原始帧，未经 ISP）→ 你的 C 程序（mmap/QBUF/DQBUF）
          ※ 使用前需按官方文档先停掉 rkipc
```

- 官方页面写明：只支持 Luckfox Pico Zero 主板；用户指南仅适用于 Buildroot 系统；V4L2 采集到的是未经 ISP 的原始图像；使用 CSI 相机前要关闭内置 rkipc；对焦要手动拧镜头，别拧过头。
- 页面没有提到该相机走 UVC，UVC 模式不确定就不做。
- 先用 VLC 验证传输，再用 OpenCV，别把问题混在一起。
- 相机标称帧率、SDK 输出帧率、PC 解码帧率、显示帧率是四回事；真实帧率用收帧计数 + 单调时钟计算。
- 不写 Sensor 内核驱动，也不改厂商镜像里已验证可用的配置。
- 你的 i.MX6ULL 与这块相机接口不同，不要把 Luckfox 的排线相机插到野火板上。

### D. 常见阻塞与替代

| 阻塞 | 先查 | 替代 |
|---|---|---|
| 模块 `invalid module format` | `uname -r`、vermagic、内核配置是否匹配 | 用匹配的源码重建，不要强制加载 |
| Luckfox 拉不出视频 | 镜像、IP、rkipc 进程、日志、排线 | 先走官方 RTSP + VLC，再接 OpenCV |
| OpenCV 打不开 RTSP | 是否带 FFmpeg/GStreamer、编码、URL | 用本地视频文件练习 |
| 找不到 `/dev/video*` | 是否已停掉 rkipc、是否在 Linux 主机上 | 读官方 `capture.c` 画流程，不虚构实测 |
| 没有合适 I2C/SPI 器件 | 接线、供电、电平 | 先做 UART/LED/按键；SPI 做回环；I2C 可试 `i2c-stub` |
| QEMU 内核难构建 | 配置、EDU 设备、initramfs | 先复用宿主内核 + 对应 headers |
| 某周超时 | 是不是 ⭐ 在挤占核心 | 删 ⭐，只留"最低可验证实验" |
