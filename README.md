# 芯片底层软件 40 周学习

从 C 和 Linux 系统编程学到 BSP、驱动、PCI/DMA，每周通过动手实验练习故障定位。

**每周只维护笔记、周报、代码。** 点击课程学习，右侧“学习记录”可直接进入对应文件；进度表为可选总览。
