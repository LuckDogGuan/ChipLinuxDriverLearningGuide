## 每周怎么用（5 步）

1. **周一**：打开 [进度总表](01-进度核对/进度总表.md) → 点本周的"计划"，看 D1–D6 任务，状态改成 🟡
2. **D1–D4 每天**：按计划看视频、动手，在本周 `note.md` 写 3 行
3. **D6**：做周实验，代码放 `code/`，截图日志放 `evidence/`，写 `report.md`
4. **自查**：对照 [每周验收清单](05-学习校验/每周验收清单.md)，做到了就在进度总表改成 ✅ 并填日期
5. **阶段末**（W10 / W20 / W25 / W32 / W40）：填 [五道门自测表](05-学习校验/五道门自测表.md)，做 [阶段自测题](05-学习校验/阶段自测题.md)

> 跑不通也可以交：在 `report.md` 写"可复现的阻塞日志 + 下一步验证清单"，状态写 ⚠️，下个小阶段继续。

## 图标速查

| 图标 | 含义 |
|---|---|
| ✅ | 必学，当周优先完成 |
| 🔧 | 动手必做，必须留证据 |
| ⏩ | 已有基础，先自测，通过就倍速或跳过 |
| ⭐ | 选读，不计验收 |
| 🟡 | 条件必学（问题需要、前置基础具备或硬件到位才学）；在进度表里也表示"进行中" |
| 📝 | 笔记与证据 |

## 上传到 Git 仓库

整个文件夹可以直接作为一个 Git 仓库上传。空的 `code/`、`evidence/` 里放了 `.gitkeep`，保证空文件夹也能上传。

```bash
git init
```

```bash
git add . && git commit -m "W01 开始"
```

建议每周 D6 结束提交一次，提交信息写周号，例如 `W03 完成：ops 虚拟设备`。大文件（视频录屏、镜像）不要提交，放网盘，在笔记里写链接。
